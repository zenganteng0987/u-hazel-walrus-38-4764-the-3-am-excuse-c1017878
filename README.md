One line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

## The entry

> My union contract says I sign nothing between 2 and 6 AM — so your 3 AM 'once-in-a-lifetime' trade can file its grievance with the sunrise.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` and prints it to stdout.
